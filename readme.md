<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Better Spawner Control is a drag-and-drop mod which disables mob spawners whenever they are surrounded by 5 torches. <strong>Why?</strong> Because those darn blazes won't stop spawning.<br><br><span style="color:#008000;font-size:16px"><strong>All types of torches are supported.</strong></span></span></p>
